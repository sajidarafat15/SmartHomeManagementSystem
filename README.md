# 🏠 Smart Home+ Management System

A mobile-based Smart Home Management System developed as a Software Engineering project. The system enables homeowners to remotely monitor and control smart home devices, manage users, improve home security, automate household tasks, and monitor energy consumption through a centralized platform.

---

## 📖 Project Overview

Smart Home+ is designed to solve common problems found in traditional homes, including:

- Energy waste
- Limited remote access
- Weak security monitoring
- Difficulty managing multiple smart devices

The system provides a secure, user-friendly, and intelligent solution by integrating smart home functionalities into a single mobile application.

---
